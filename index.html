VCBench — LLM evaluation on highly imbalanced data

2026

Companion code to an SSRN preprint: evaluating locally run open-weight LLMs (Qwen3-32B via Ollama, quantised GGUF) on binary classification with a very low positive rate. Compares vanilla, chain-of-thought, few-shot and hybrid prompting with F0.5, precision, recall, positive-prediction rate, PR curves, bootstrap and Wilson intervals, against a TF-IDF logistic baseline. The documented conclusion is a negative one: small-sample F0.5 gains are unstable without calibration diagnostics, and the classical baseline still wins.

  • LLM evaluation
  • Qwen3 / Ollama
  • Calibration
  • F0.5
  • Bootstrap CIs

Hospital Digital Twin

2026

A SimPy discrete-event twin of a hospital — ER, ICU and ward — with realistic boarding, where a full ICU blocks ER beds and congestion cascades backwards. A gradient-boosting model forecasts peak ICU load 24 hours ahead, backtested out-of-sample against a naive baseline. Under an epidemic wave, a targeted capacity package takes the median ER wait from 4,613 to 71 minutes and treats 63% more patients; adding ER beds instead would have matched the headline number while tripling boarding time. Two interfaces on one engine: a Flask/ECharts command centre and a Streamlit dashboard.

  • SimPy
  • Gradient boosting

Multimodal Medical QA with BiomedCLIP

2026

Zero-shot medical visual question answering on WorldMedQA/V. BiomedCLIP is a CLIP-style model, so it cannot generate an answer — the task is posed as retrieval instead: every answer option becomes a candidate prompt, each is scored against the image, and the highest similarity wins. The app shows the score for every option rather than just the winner, which makes the failure mode visible where distractors look like the right answer. Includes a sampled batch evaluation against ground truth.

Smart Reading Interface

2026

A hands-free reader: words highlight as you say them aloud, and MediaPipe hand gestures drive zoom and page turns without touching the keyboard. The gesture classifier is geometric rather than learned — pinch and spread from thumb-to-index distance normalised by hand size, swipes from centroid velocity, with a cooldown so a held gesture does not fire repeatedly. Inspectable rules beat a black box when the model is steering someone's reading interface.
